# Contributor and agent instructions

Use Beads for task tracking when a workspace is configured. Read skills/pm-beads/SKILL.md for issue-writing conventions and structured asks. Read CONTRIBUTING.md for setup, quality gates, and the read-only /api/check endpoint. Never expose the unauthenticated server publicly. Run typecheck, test, lint, build, and test:e2e before submitting changes. Do not publish to npm.
